# Duilib 框架知识

## 概述

Duilib 是 Windows 平台下的轻量级 DirectUI 框架，采用"无句柄控件"设计——整个窗口只有一个 HWND，所有 UI 控件均为逻辑绘制。广泛应用于国内 IM 客户端、安全软件、工具类桌面应用。
