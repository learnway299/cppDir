# 08 - 离屏渲染 (OSR)

## 核心概念

**Windowless / Off-Screen Rendering**：不创建可见子窗口，CEF 通过 **`CefRenderHandler`** 把帧像素（及脏矩形）交给宿主，由宿主 OpenGL/Direct3D/自绘呈现。

适用：与游戏引擎叠加、特殊圆角裁剪、无独立 HWND 的合成。

---

## 关键回调

| 回调 | 作用 |
|------|------|
| `GetViewRect` | 视口大小 |
| `OnPaint` | 像素缓冲与脏区 |
| 输入 | 宿主把鼠标键盘事件注入 `CefBrowserHost` |

需开启 settings 中的 windowless 相关开关。

---

## 代价

| 代价 | 说明 |
|------|------|
| 实现复杂 | 输入法、光标、拖拽、加速合成都要自己对接 |
| 性能 | 错误用法导致 CPU 拷贝贵；需关心缓冲格式与更新频率 |
| 调试 | 比有窗更难「直接看 HWND」 |

能有窗就有窗——面试加分句。

---

## 常见面试题

**Q1：OSR 是什么？何时用？**  
答：无子窗，像素回调给宿主；需要与自有渲染管线合成时用。

**Q2：OnPaint 要注意什么？**  
答：线程、缓冲寿命、脏区、缩放因子；勿在回调里重活堵死。

---

## 实战要点

- 先验证有窗嵌入，再切 OSR。  
- 固定帧率与脏区更新，避免每帧全量上传。
