# Chromium 内核深入 (Chromium Internals)

## 简介

Chromium 是 Chrome、Edge、CEF、Electron、Qt WebEngine 等产品的核心引擎。理解 Chromium 内部机制对于 C++ 客户端开发、浏览器内核开发、前端容器优化等岗位面试至关重要。

本模块从架构到细节，由浅入深覆盖 Chromium 内核的核心知识点。
