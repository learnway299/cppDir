# 03 - 网络层 (Network Layer)

## 简介

网络层负责跨网络的数据包路由和转发。

---

## 2. 子网划分

```
192.168.1.0/24 划分为 4 个子网：

网络地址        子网掩码          可用主机
192.168.1.0     /26 (255.255.255.192)   1-62
192.168.1.64    /26                     65-126
192.168.1.128   /26                     129-190
192.168.1.192   /26                     193-254
```

## 3. 路由

### 3.1 路由表

```bash
# 查看路由表
route -n
ip route

# 输出示例
Destination     Gateway         Genmask         Iface
0.0.0.0         192.168.1.1     0.0.0.0         eth0   # 默认网关
192.168.1.0     0.0.0.0         255.255.255.0   eth0   # 直连网络
```

### 3.2 路由算法

- **距离矢量**：RIP（跳数）
- **链路状态**：OSPF（带宽、延迟）
- **路径矢量**：BGP（AS 路径）

## 4. ICMP

**ICMP**：网络诊断和错误报告。

```bash
# ping：测试连通性
ping 8.8.8.8

# traceroute：跟踪路径
traceroute google.com
```

---

## 5. NAT

**NAT (Network Address Translation)**：私有地址转换为公网地址。

```
内网 PC                 NAT 路由器              互联网
192.168.1.10:5000  →   203.0.113.1:10001  →   服务器
192.168.1.11:5001  →   203.0.113.1:10002  →   服务器
```

## 6. IPv6

| 特性 | IPv4 | IPv6 |
|------|------|------|
| 地址长度 | 32 位 | 128 位 |

## 7. 面试常见问题

**Q1：IP 分片是什么？**
- 数据包超过 MTU（通常 1500 字节）时分片
- 由目的主机重组

**Q2：TTL 的作用？**
- 防止数据包无限循环
- 每经过一跳减 1，为 0 时丢弃

**Q3：NAT 的优缺点？**
- 优点：节省公网 IP，隐藏内部结构
- 缺点：打破端到端模型，P2P 困难
