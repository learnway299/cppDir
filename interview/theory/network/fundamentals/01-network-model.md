# 01 - 网络模型 (Network Model)

## 简介

网络模型定义了网络通信的层次结构和各层功能，是理解网络协议的基础。

---

## 1. OSI 七层模型

| 层次 | 名称 | 功能 | 协议/设备 |
|------|------|------|-----------|
| 7 | 应用层 | 为应用程序提供网络服务 | HTTP, FTP, SMTP, DNS |
| 6 | 表示层 | 数据格式转换、加密 | SSL, JPEG, ASCII |
| 5 | 会话层 | 建立、管理会话 | RPC, NetBIOS |
| 4 | 传输层 | 端到端可靠传输 | TCP, UDP |
| 3 | 网络层 | 路由和寻址 | IP, ICMP, 路由器 |
| 2 | 数据链路层 | 帧传输、错误检测 | Ethernet, 交换机 |
| 1 | 物理层 | 比特流传输 | 网线、光纤、集线器 |

---

## 2. TCP/IP 四层模型

| TCP/IP 层 | 对应 OSI | 协议 |
|-----------|----------|------|
| 应用层 | 应用+表示+会话 | HTTP, FTP, DNS, SMTP |
| 传输层 | 传输层 | TCP, UDP |
| 网络层 | 网络层 | IP, ICMP, ARP |
| 网络接口层 | 数据链路+物理 | Ethernet, Wi-Fi |

---

## 3. 数据封装

```
发送方（自上而下）：
┌─────────────────────────────────────────────────────────┐
│ 应用层 │ 数据                                           │
├────────┴────────────────────────────────────────────────┤
│ 传输层 │ TCP头 │ 数据                    │ → 段(Segment) │
├────────┴───────┴────────────────────────────────────────┤
│ 网络层 │ IP头 │ TCP头 │ 数据             │ → 包(Packet)  │
├────────┴──────┴───────┴─────────────────────────────────┤
│ 链路层 │ 帧头 │ IP头 │ TCP头 │ 数据 │ FCS│ → 帧(Frame)  │
└─────────────────────────────────────────────────────────┘
```

## 4. 面试常见问题

**Q1：OSI 和 TCP/IP 的区别？**
- OSI：理论模型，7 层
- TCP/IP：实际使用，4 层
- TCP/IP 合并了 OSI 的上三层和下两层

**Q2：各层典型设备？**
- 物理层：集线器、中继器
- 数据链路层：交换机、网桥
- 网络层：路由器
- 传输层及以上：主机

**Q3：为什么要分层？**
- 简化设计
- 模块化，易于维护
- 各层独立发展
- 促进标准化
