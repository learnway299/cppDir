# 02 - 链路层 (Link Layer)

## 简介

链路层负责相邻节点之间的数据帧传输。

---

## 1. 以太网 (Ethernet)

### 1.1 以太网帧格式

```
┌─────────┬─────────┬──────┬──────────┬─────┬─────┐
│ 前导码  │ 目的MAC │源MAC │ 类型/长度│ 数据│ FCS │
│ 8字节   │ 6字节   │6字节 │   2字节  │46-1500│4字节│
└─────────┴─────────┴──────┴──────────┴─────┴─────┘
```

### 1.2 MAC 地址

- 48 位，全球唯一
- 格式：`AA:BB:CC:DD:EE:FF`
- 前 24 位：厂商标识 (OUI)
- 后 24 位：设备标识

---

## 2. ARP 协议

**ARP (Address Resolution Protocol)**：将 IP 地址映射为 MAC 地址。

```
ARP 请求/响应流程：

1. A 想发送给 B (192.168.1.2)，但不知道 B 的 MAC
2. A 广播 ARP 请求："谁的 IP 是 192.168.1.2？"
3. B 收到后回复："我的 MAC 是 xx:xx:xx:xx:xx:xx"
4. A 缓存到 ARP 表
```

```bash
# 查看 ARP 缓存
arp -a
# Linux
ip neigh
```

## 3. 交换机 vs 集线器

| 特性 | 集线器 (Hub) | 交换机 (Switch) |
|------|-------------|-----------------|
| 工作层 | 物理层 | 数据链路层 |
| 转发方式 | 广播 | 按 MAC 定向转发 |
| 冲突域 | 整个网络 | 每个端口独立 |
| 带宽 | 共享 | 独享 |

---

## 4. VLAN

**VLAN (Virtual LAN)**：逻辑上划分广播域。

```
物理网络：
[PC1]──[交换机]──[PC2]
        │
       [PC3]

逻辑 VLAN：
VLAN 10: [PC1], [PC2]  (销售部)
VLAN 20: [PC3]         (技术部)
```

## 5. 面试常见问题

**Q1：MAC 地址和 IP 地址的区别？**
- MAC：物理地址，48 位，局域网寻址
- IP：逻辑地址，可变，跨网络寻址

**Q2：ARP 攻击是什么？**
- 伪造 ARP 响应，将流量重定向到攻击者
- 防御：静态 ARP、ARP 检测

**Q3：交换机如何学习 MAC 地址？**
- 收到帧时，记录源 MAC 和端口对应关系
- 查表转发，未知则洪泛
