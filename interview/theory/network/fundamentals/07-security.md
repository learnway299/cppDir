# 07 - 网络安全 (Network Security)

## 简介

网络安全是保护网络通信不被窃听、篡改和伪造。

---

## 1. 加密算法

### 1.1 对称加密

| 算法 | 密钥长度 | 特点 |
|------|----------|------|
| AES | 128/256 位 | 安全高效，推荐 |
| DES | 56 位 | 已不安全 |
| 3DES | 168 位 | 较慢 |

### 1.2 非对称加密

| 算法 | 用途 |
|------|------|
| RSA | 加密、签名 |
| ECDSA | 签名（更短密钥） |
| ECDHE | 密钥交换 |

### 1.3 哈希算法

| 算法 | 输出长度 | 安全性 |
|------|----------|--------|
| MD5 | 128 位 | 不安全 |
| SHA-1 | 160 位 | 不推荐 |
| SHA-256 | 256 位 | 推荐 |

## 2. TLS/SSL

### 2.1 TLS 握手

```
客户端                              服务器
  │                                   │
  │ ─── ClientHello ────────────────► │
  │     (支持的加密套件、随机数)        │
  │                                   │
  │ ◄── ServerHello ──────────────── │
  │     (选择的套件、随机数、证书)      │
  │                                   │
  │ ─── 密钥交换、Finished ──────────► │
  │                                   │
  │ ◄── Finished ─────────────────── │
  │                                   │
  │ ════ 加密通信 ═════════════════   │
```

### 2.2 证书链

```
根证书 (Root CA)
    │
    └─── 中间证书 (Intermediate CA)
              │
              └─── 服务器证书
```

## 3. 常见攻击

| 攻击 | 描述 | 防御 |
|------|------|------|
| **中间人** | 拦截修改通信 | HTTPS, 证书验证 |
| **SQL 注入** | 恶意 SQL 语句 | 参数化查询 |
| **XSS** | 注入恶意脚本 | 输入过滤、CSP |
| **CSRF** | 伪造请求 | Token 验证 |
| **DDoS** | 流量攻击 | CDN、限流 |

---

## 4. HTTPS 安全

```
HTTPS 提供：
1. 加密：对称加密数据
2. 认证：证书验证身份
3. 完整性：MAC 防篡改
```

---

## 5. 面试常见问题

**Q1：对称加密和非对称加密区别？**
- 对称：速度快，密钥分发难
- 非对称：速度慢，解决密钥分发

**Q2：HTTPS 如何防止中间人攻击？**
- 证书验证服务器身份
- 密钥交换防止窃听

**Q3：如何防止 SQL 注入？**
- 使用参数化查询
- 输入验证和转义
